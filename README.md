
# Motus Game – C Project

## Project Overview

**Motus Game** is a **word guessing game** developed as part of **ENICarthage 2023–2024**. The game includes **dynamic dictionary management**, word validation algorithms, scoring mechanisms, and save/load functionality.

The project was designed to enhance **algorithmic thinking, programming precision, and problem-solving skills** in a playful context.

---

## Features

* **Dynamic dictionary management**: add, remove, and manage words efficiently.
* **Word validation algorithms** to ensure user guesses are correct and within game rules.
* **Scoring system**: calculates points based on guesses, attempts, and game progression.
* **Save and load game states**, allowing players to resume games later.
* **User-friendly console interface** for intuitive gameplay.

## Installation / Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/MotusGame.git
cd MotusGame
```

2. Compile the program:

```bash
gcc -o motus motus.c
```

3. Run the game:

```bash
./motus
```

> Ensure you have a **C compiler** installed (e.g., GCC).
